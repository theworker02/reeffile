# reeffile

Reef validation gates for file inputs before they hit prod.

**Site:** https://theworker02.github.io/reeffile/

## Install / run

```bash
git clone https://github.com/theworker02/reeffile.git
cd reeffile
node src/cli.js
node --test
```
